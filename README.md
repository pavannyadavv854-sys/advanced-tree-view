# Advanced Tree View Component 🌳

This is a **React + TypeScript Tree View component** built as a learning project.  
It demonstrates how to handle **hierarchical data** with common features like drag & drop, search, and context actions.

The goal of this project is to show clean component structure, state handling, and practical UI interactions that are often used in real applications.

---

## 👋 Overview

The Tree View displays data in a **folder–file style structure**.  
Users can expand nodes, reorder items, select them, and add new nodes dynamically.

This kind of component can be useful for:
- File explorers
- Category management systems
- Menu builders
- Admin panels

---

## ✨ Features

- 📁 Folder and file hierarchy
- 🔽 Expand / collapse nodes
- 🔀 Drag and drop reordering
- ✅ Checkbox selection
- 🔍 Search and filter nodes
- 🖱 Right-click context menu
- ➕ Add new folders and files
- 🧩 Written in TypeScript

---

## 🛠 Tech Stack

- **React**
- **TypeScript**
- **@dnd-kit** (for drag and drop functionality)
